mockDebugPlugin の解説

debug npm パッケージは CJS の module.exports を使う。Cloudflare Workers の workerd ランタイムには module.exports グローバルがないため、そのままでは実行時エラーになる。

これは Astro エコシステムの推移的依存 (transitive dependency) に起因する問題であり、プロジェクト本体のコードとは無関係。

解決策として astro.config.mjs 内に Vite プラグインを定義し、resolveId フックで debug のモジュール解決をインターセプトして no-op 実装に差し替える:

function mockDebugPlugin() {
  return {
    name: "mock-debug",
    enforce: "pre",
    resolveId(id) {
      if (id === "debug" || id.endsWith("/debug/src/index.js")) {
        return "\0mock-debug"; // 仮想モジュール ID
      }
    },
    load(id) {
      if (id === "\0mock-debug") {
        // no-op: enable/disable は何もしない
        return `export default function debug() { return function() {}; };
debug.enable = () => {};
debug.disable = () => {};`;
      }
    },
  };
}

CI / 観測

GitHub Actions は未設定。 デプロイは手動で pnpm deploy を実行する。CI が必要になった場合は別途 .github/workflows/ を追加する。
  • 観測 — wrangler.jsonc の observability.enabled: true により、Cloudflare ダッシュボードでリクエスト数・エラー率・レイテンシを確認できる
  • ローカルデータ — miniflare の D1 は .wrangler/state/v3/d1/ に SQLite ファイルとして保存される。.gitignore で除外済み
  • ビルド成果物 — dist/ も .gitignore で除外済み
