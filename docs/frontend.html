レイアウト

src/layouts/Layout.astro — 全ページが使う唯一のレイアウト。

  • src/styles/global.css をインポート（デザイントークン定義）
  • <html lang="ja"> + viewport + favicon
  • .app-shell で最大幅 32rem、中央配置
  • <ToastRegion client:load /> を常時マウント → 全ページでトーストが使える
  • <slot /> でページコンテンツを挿入

アイランドモデル

Astro の client:load ディレクティブで SolidJS コンポーネントをハイドレーション。インタラクティブな機能はすべて SolidJS アイランドに委譲し、Astro ページは SSR データ取得とレンダリングのみ担う。

アイランドマウント場所初期データの受け渡し
<Dashboard client:load>index.astrolists（最新 3 件）と origin を props で渡す
<HistoryList client:load>history.astrolists（全件）を props で渡す
<RegisterPage client:load>[id]/register.astrolist と items を props で渡す
<ToastRegion client:load>Layout.astroprops なし。モジュールレベルのシグナルを購読
/[id]/room の <ItemList readonly> は client:* ディレクティブを持たないため SSR-only。公開ページはサーバー側で完全に HTML 化されて返される。

フィーチャーコンポーネント (src/components/features/)

コンポーネントファイル責務

各フィーチャーコンポーネントの詳細 props

props: { lists: List[]; origin: string }

props: { onCreated: (list: List) => void }

HistoryList

props: {
  lists: List[];
  maxItems?: number;      // 上限件数（index ページでは 3）
  newList?: List | null;  // 先頭に即時挿入するリスト
}

RegisterPage

props: { list: List; items: Item[] }

RegisterForm

props: {
  listId: string;
  onItemAdded: (item: Item) => void;
}

ItemList

props: {
  listId: string;
  items: Item[];
  readonly?: boolean;      // true = 公開ページ（編集 UI 非表示）
  onItemUpdated?: () => void;
}

ユーティリティ

画像圧縮 (src/lib/image-utils.ts)

compressImage(file, options?) — File を受け取り、Canvas で縮小・JPEG 再エンコードして新しい File を返す。

オプションデフォルト説明
maxWidth1920最大幅（px）
maxHeight1920最大高さ（px）
quality0.8JPEG 品質（0–1）

アスペクト比を保ちながら縮小。拡張子は .jpg に統一。RegisterForm が upload 前に自動呼び出し。

トーストシステム (src/lib/api.ts / src/components/ui/toast.tsx)

showToast の仕組み

showToast(title, type, description?) はモジュールレベルのシグナルキューに積む。Layout.astro が常時マウントしている <ToastRegion client:load /> がそのシグナルを購読し、<Portal> 経由でページ最上位に表示する。

  • type: "success" | "error" | "info"
  • 約 4 秒後に自動消滅
  • 各フィーチャーコンポーネントは import { showToast } from "~/components/ui/toast" でインポートして呼ぶだけ

その他ユーティリティ (src/lib/utils.ts)

  • cx(...classes) — クラス名結合ヘルパー（CSS Modules でクラス上書き可能にするため全コンポーネントで使用）
  • formatDate(date, opts?) — Intl.DateTimeFormat で日付文字列化。デフォルトは numeric/2-digit/2-digit
